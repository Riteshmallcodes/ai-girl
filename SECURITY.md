# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **Ai Girl**, please do **NOT** open a public issue.

Instead, please send an advisory email to `security@example.com` or open a private GitHub Security Advisory. We will investigate promptly.
