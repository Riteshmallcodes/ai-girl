# Contributing to Ai Girl

Thank you for your interest in contributing to **Ai Girl**! 🎉

## Code of Conduct

All contributors are expected to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute

1. **Fork the Repository**: Create your own fork of the project.
2. **Create a Feature Branch**: `git checkout -b feature/amazing-feature`.
3. **Commit Your Changes**: Follow clear commit message conventions.
4. **Run Tests**: Ensure all automated tests and linters pass.
5. **Open a Pull Request**: Submit your PR with a descriptive summary of your changes.

## Development Workflow

- Follow established architectural style guides.
- Write unit tests for new features.
- Update documentation in `README.md` where appropriate.
